# LimbahLaut
Laut bukan tempat sampah. Limbah laut merupakan ancaman serius bagi ekosistem laut, kehidupan biota, dan masa depan bumi. Melalui website ini, mari tingkatkan kesadaran tentang pencemaran laut, mengenali dampaknya, dan mengambil langkah nyata untuk menjaga laut tetap bersih demi generasi mendatang.  Laut yang bersih dimulai dari langkah kecil kita.
